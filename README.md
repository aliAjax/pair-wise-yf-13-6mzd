# 油料与值守对账台（hxyfront-62001）

面向船舶轮机值班的油料抄表与交接班对账系统。轮机员每班按观测时刻抄录各油舱**液位、温度、密度**，系统折算存量并以**相邻两次实测差**计算油耗，与交班申报耗油对账；超差则交接签字立即失效，差异油舱进入轮机长复核。数据全部保存在浏览器本地（localStorage）。

## 业务规则

- **按观测时刻存读数**：每个油舱的液位/温度/密度按"观测时刻"存档，经舱容系数、温度体积修正（基准 15℃）、实测密度折算为存量（吨）。
- **油耗只认实测差**：每班各舱耗油 = 班前边界实测存量 − 班末边界实测存量；边界缺测时用班内相邻两次有效实测兜底，绝不采用申报值倒推。
- **晚到补录只进历史**：对已确认（封存）班次，补录落在已有观测时刻时**不能回改原始读数**，而是进入复核队列，标记 `pending`，等待轮机长裁定。
- **同一观测时刻只留一条有效值**：
  - 未确认班次：同刻重抄直接以新值替换，旧值转 `superseded` 留痕；
  - 已确认班次：补录与原值并存，仅原 `active` 生效，新值 `pending` 待复核；采纳后旧值 `superseded`、补录转 `active`，封存快照始终不动；驳回则补录 `rejected`。
- **对账超差 → 签字立即失效**：单舱差异或本班总差异超过允许值时，交接签字即刻置为失效（`voided`），看板、趋势、摘要统一列出差异油舱；差异经补录复核消除后，轮机长可复核复签（原失效记录保留审计）。
- **旧记录缺密度迁移**：历史读数缺实测密度时自动迁移为"待补录"，保留液位/温度但不参与折算与对账，补录密度后恢复参与计算。
- **数据留在浏览器**：localStorage 键 `fuel-watch-reconcile-v1`，支持 JSON 导出/导入、重置演示数据。

## 页面

| 标签 | 功能 |
| --- | --- |
| 看板 | 签字失效告警与差异油舱表、各舱最新折算存量、KPI、近期班次状态带 |
| 抄表录入 | 多舱同一观测时刻批量抄表、现场/纸表补录来源、实时折算预览、同刻冲突提示 |
| 交班对账 | 主机转速、各舱申报耗油录入、实时对账、签字封存/超差强制交班即失效、历史班次复核复签 |
| 历史与复核 | 缺密度迁移补录、晚到补录复核裁定（采纳/驳回）、全量留痕检索与筛选 |
| 趋势 | 各舱折算存量折线（差异油舱红色高亮）、班次堆叠油耗柱图（失效班红框） |
| 摘要与设置 | 逐班次对账摘要（可打印/PDF）、允许差异与舱容表设置、本地数据管理 |

## 技术栈

React 19 + Vite 7 + TypeScript（无第三方 UI/图表库，趋势图为内联 SVG）。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62001
```

## 校验

```bash
npm test         # tsc 类型检查 + 领域规则验证(34项) + store 动作集成验证(25项)
npm run build
```

首次打开会自动生成一套演示数据：4 个油舱、连续 8 个班次边界读数、1 个因超差已失效待复核的 16-20 班、1 条待裁定晚到补录、2 条缺密度迁移记录，以及一个可直接签字的进行中班次。在"摘要与设置"页可重置或清空。
